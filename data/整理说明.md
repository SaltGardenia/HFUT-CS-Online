# 课件与期末题整理说明

本文件夹将 4 个 HFUT 资料仓库的全部内容（8210 个文件，无一遗漏）合并整理为统一的目录结构：

```
课件与期末题整理/
├── 大一上 … 大四下        # 8 个学期文件夹
│   └── <课程>/
│       ├── 课件/          # PPT、讲义、按章课件
│       ├── 试题/          # 试卷、真题、题库、复习题、习题
│       └── 附件/          # 其余一切：实验、作业、报告、代码、笔记、指导书等
├── 文件清单.csv            # 每个文件的 来源仓库 → 目标路径 → 类别 → 处理方式
├── 分类统计.txt            # 按目标目录的文件数统计
└── 整理说明.md             # 本文件
```

> 注：原「公共课与杂项/」（四六级、思政、培养方案等 288 份文件）在站点化阶段已整体移除——本项目只收录学期课程资料，该部分不再整理维护。文件清单.csv / 分类统计.txt 中对应条目仅作历史溯源保留。

## 学期归属依据

以 sunmiao 仓库附带的官方《合肥工业大学 2019 版计算机科学与技术专业指导性教学计划》的"开课学期"为基准，与各仓库实际修读记录交叉验证：

- **两个及以上实际来源一致时从实际**：如编译原理（培养方案大二上，但 sunmiao+mox 实际均在大二下 → 大二下）、人工智能原理（→ 大三上）；
- **实际来源冲突时以培养方案裁决**：如汇编（sunmiao 大二下 vs mox 大二上，培养方案第 3 学期 → 大二上）、数据库系统（→ 大三下）；
- **只有培养方案可依时从培养方案**：如线性代数 → 大一下、大学物理C → 大二上、数字媒体技术/计算机图形学 → 大二下；
- **培养方案没有的课**从实际仓库：如移动计算与应用开发 → 大三上（sunmiao）、人工智能经济学 → 大三下（luna）、分布式程序设计 → 大四上、创新实践 → 大四下。

个别课程各校区/各年级开课学期本就有差异，如与你的培养方案不符，可按文件清单.csv 溯源后自行移动。

## 课件 / 试题 / 附件 三分类规则

按文件名自动分类（同一源目录的文件会按名拆到不同类别，属正常现象）：

- **课件**：PPT/PPTX 扩展名；或文件名含 课件/讲义/PPT/slides/lecture/第N章/chapter；
- **试题**：文件名含 试题/试卷/真题/考试题/复习题/练习题/习题/题库/笔试/测验/exam/quiz（四六级资料按 cet/四级/六级 判定）；作业答案、习题答案归附件；
- **附件**：其余全部（实验、作业、报告、代码、笔记、指导书、数据集等）。

规则由脚本自动执行，个别文件归类可能不完美，可用文件清单.csv 溯源后手工调整。
